# ARQ//QUEST

Arcade de revisão de Arquitetura Computacional feito com HTML, CSS e JavaScript puros.

## Como jogar

- **Crossmemory:** leia as pistas, digite diretamente nas casas, confira o mapa e use a dica quando precisar.
- **Termo de bits:** descubra o termo de três letras em até seis tentativas. Verde indica posição certa; âmbar indica letra existente em outra posição.
- **Organiza o sistema:** arraste os 16 termos para os quatro grupos conceituais e verifique a organização.

## Termos da cruzadinha

| Termo | Pista |
| --- | --- |
| Memória de massa | Armazena muitos dados mesmo quando o computador está desligado. |
| Microcontrolador | Chip compacto que reúne processamento, memória e entradas para controlar sistemas. |
| Address bus | Caminho que informa a posição de memória ou dispositivo acessado. |
| Data bus | Caminho por onde circulam os valores entre os componentes. |
| Quad core | Processador que possui quatro núcleos trabalhando em paralelo. |
| EEPROM | Memória não volátil que pode ser apagada e regravada eletricamente. |
| Cache | Memória pequena e veloz que guarda dados usados com frequência. |
| DMA | Permite transferências entre memória e periféricos sem ocupar continuamente o processador. |
| RAM | Memória de trabalho rápida, cujo conteúdo se perde sem energia. |
| ROM | Memória usada para guardar instruções que permanecem disponíveis sem energia. |
| ULA | Parte do processador que executa contas e operações lógicas. |
| UC | Parte do processador que coordena a execução das instruções. |

## Dicas progressivas

O botão **dica** percorre três níveis de apoio para cada conceito: função, exemplo cotidiano e explicação técnica. As mesmas dicas são usadas na cruzadinha e no arquivo de apoio dos outros desafios.

- **Memória de massa:** armazeno grandes quantidades por longos períodos; guardo documentos, fotos, vídeos e programas; preservo informações sem energia.
- **DMA:** permito transferências sem controle contínuo do processador; ajudo dispositivos enquanto a CPU trabalha; transfiro diretamente entre periféricos e memória principal.
- **Cache:** armazeno informações temporariamente para acelerar o processamento; facilito acessos frequentes; sou pequena, rápida e geralmente integrada ao processador.
- **Address bus:** indico a localização de uma informação; aponto o endereço antes da busca; transporto endereços entre componentes.
- **Data bus:** transporto informações entre componentes; levo dados ao processador; minha largura define quantos bits podem ser transferidos simultaneamente.
- **Quad core:** permito tarefas simultâneas com quatro núcleos; divido tarefas entre unidades de processamento; reúno quatro núcleos no processador.
- **Microcontrolador:** controlo sistemas por instruções programadas; controlo sensores, motores e equipamentos; reúno processamento, memória e periféricos em um chip.
- **RAM:** armazeno dados e programas em execução; ajudo a manter programas abertos; perco informações sem energia.
- **ROM:** armazeno instruções que permanecem disponíveis; conservo informações após desligar; sou memória não volátil para instruções permanentes.
- **ULA:** realizo operações matemáticas e lógicas; calculo e comparo valores; executo adição, subtração, AND e OR.
- **UC:** coordeno componentes do processador; organizo etapas de uma instrução; interpreto instruções e envio sinais de controle.
- **EEPROM:** armazeno informações modificáveis eletricamente; guardo configurações sem energia; permito apagar e regravar dados eletricamente.
